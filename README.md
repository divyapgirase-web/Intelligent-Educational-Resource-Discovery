# 📚 Intelligent Educational Resource Discovery and Analytics System

## 📌 Project Overview

The Intelligent Educational Resource Discovery and Analytics System is a web-based application developed using Python and Streamlit.

The system helps users discover educational resources, search resources, filter them by category, automatically classify educational webpages, and analyze available resources using a simple analytics dashboard.

## 🎯 Objectives

- Discover useful educational resources
- Search educational resources easily
- Filter resources based on category
- Automatically classify educational webpages
- Extract webpage title and content
- Display resource analytics
- Provide a simple and user-friendly interface

## ✨ Features

### 🔎 Resource Search
Users can search educational resources using keywords such as Python, Pandas, SQL, HTML, Cloud, and Machine Learning.

### 📂 Category Filtering
Resources can be filtered into categories such as:

- Programming
- Artificial Intelligence
- Data Science
- Database
- Web Development
- Cloud Computing
- Cyber Security
- Tools

### 🌐 Educational Resource Crawler
Users can enter an educational webpage URL.

The system extracts:

- Page title
- Webpage content
- URL

### 🤖 Automatic Classification
The system automatically detects the category of an educational resource using keyword-based classification.

### 📊 Analytics Dashboard
The dashboard displays:

- Total Resources
- Total Categories
- Search Results
- Resources by Category
- Resource Dataset
